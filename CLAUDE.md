# PyOptik agent instructions

Project overview, installation and usage are in [README.rst](README.rst). Tests
live in `PyOptik/tests/`; install them with `pip install -e ".[testing]"` and run
`pytest` from the repository root.

## Complexity report

This repository's complexity entry point emits the team plugin's complexity report
contract `schemaVersion: 1` JSON on stdout. From the repository root:

```sh
python scripts/complexity.py <base> <head> <path.py>...
```

- Inputs: base and head revisions (compared directly, committed content only),
  then 1–100 literal repository-relative `.py` paths. `PyOptik/_version.py` is
  generated by setuptools_scm and reported as `excluded`.
- Language and analyzer: Python 3.10; radon `cc` 6.0.1, configured by
  `scripts/complexity-config.json`.
- Prerequisites: Git on PATH and `pip install -e ".[testing]"` on Python 3.10.
  The command never installs or sets anything up.
- Effects: reads Git objects by running local `git` in the repository root, and
  runs radon in an empty temporary directory that it removes on exit. It parses
  source but never imports or executes it, writes nothing to the repository and
  uses no network.
- Failure: exits 1 with a `failed`, `unavailable`, `unsupported` or `incomparable`
  report and no metrics.

Details are in [the complexity reporting guide](docs/complexity-reporting.md).
